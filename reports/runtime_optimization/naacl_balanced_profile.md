# LUNA_NAACL_PROFILE

Status: policy-only artifact, ready after `WAVE0_ACCEPTED`.

This profile records the NAACL-balanced slice for scientific traceability. It is not a benchmark, experiment, or execution plan. Activation is default-off, requires explicit opt-in after Wave 0 acceptance, and real execution is prohibited.

## Retained scope

- Q3 retains the audited local systems PhoBERT, Vistral, and full ViPragSent.
- Each retained local system has budgets `32`, `128`, `512`, and `full`, across seeds `20260521`, `20260522`, and `20260523` (36 local cells).
- The frozen Q3 inventory and Azure registry also define four reduced Azure comparison rows, one each for budgets `32`, `128`, `512`, and `full`; Azure has no seed axis (`seed: null`). The balanced Q3 profile therefore contains 40 total rows: 36 local cells plus 4 Azure rows.
- Q2 retains its three audited seeds: `20260521`, `20260522`, and `20260523`.
- Q2 retains the six variants declared by the audited Q2 protocol.
- Q1b remains evaluation-only: official external tests use approved upstream checkpoints, with no training and zero optimizer steps.
- The Q1b binding enumerates all 22 consumers: 21 exact seeded trainable-checkpoint edges and the Azure approved-output consumer with seed `null`.

## Exclusions and invariants

Only XLM-R Q3 and Q3 budgets `64` and `256` are excluded. The reduced Azure comparison rows remain required even though Azure is non-local. The original profile and all audited source files remain untouched. Fixture, synthetic, and run-data rows cannot enter aggregation.

Aggregation is profile-aware and fail-closed: it consumes exactly the declared 36-cell local Cartesian product plus four protocol-defined Azure rows, rejects missing rows, rejects invented Azure seeds, and does not mix excluded budgets or systems. Q1b aggregation first resolves an exact approved producer for the consumer, requires the same seed and matching checkpoint key, and blocks if that dependency is absent; training metrics are never substituted for Q1b evaluation metrics.

The binding is generated by the pure validator from the existing Q1b dependency graph. The artifact records both the graph digest and a digest of the graph’s source inputs; drift in graph status, consumer, producer, producer kind, checkpoint key, or seed fails closed. The current graph represents Azure as self-covered, so the profile records its approved-output producer explicitly and preserves the required seed-`null` case.

The validator also records digests for the Q3 alias map, Q3 budget protocol, Azure execution registry/inventory source, Q2 protocol, and locked seed source. It checks the retained aliases, Azure fixed-prompt/no-checkpoint semantics, XLM-R and budgets `64`/`256` exclusions, all three local seeds, the 36-cell local Q3 Cartesian count, and the four seedless Azure rows against those sources.

Source references and machine-readable invariants are recorded in `naacl_balanced_profile.json`; the declarative activation policy is in `configs/experiments/naacl_balanced_runtime_profile.yaml`.
